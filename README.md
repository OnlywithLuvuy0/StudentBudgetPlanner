Project Title: Personal Finance & Student Budget Planner
Your Name: Tumelo Luvuyo Mokwena 

Description:
A console-based C# application designed to help students track daily expenses, manage monthly allowances, monitor savings goals, and view budget statistics.

Features Built:
- Log daily expenses with descriptions, amounts, and categories (Food, Transport, Books, Entertainment).
- View all logged transactions and check overall budget status.
- Search for specific expenses by description (case-insensitive search).
- Calculate total spent and view remaining monthly allowance against a set savings goal.
- Generate budget statistics showing the highest and lowest expenses.
- Automatic over-budget warning when spending exceeds 90% of the total allowance.
